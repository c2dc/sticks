# Diário de desenvolvimento

Este diretório registra, por dia, o que foi feito, como foi validado, quais
problemas foram encontrados e qual é o ponto exato de continuidade. A ideia é
manter um histórico objetivo para as reuniões de acompanhamento e permitir que
o desenvolvimento seja retomado no Codex, no Kiro ou manualmente.

## Convenção para os próximos dias

Crie um arquivo `AAAA-MM-DD.md` com: objetivo do dia, avanços, evidências de
teste, decisões, pendências e próximo passo. Atualize também o checklist em
`.kiro/specs/pipeline-ui/tasks.md` quando uma tarefa estiver comprovadamente
concluída.
